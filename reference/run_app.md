# Launch Pop-Up Scout

Opens the Pop-Up Scout Shiny app, which helps someone planning a
clothing pop-up in Melbourne's CBD compare street locations by foot
traffic during their own trading days, hours and months.

## Usage

``` r
run_app()
```

## Value

Called for its side effect of starting the app. Does not return a useful
value.

## Examples

``` r
if (interactive()) {
  run_app()
}
```
